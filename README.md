# 황금별을 잡아라

제공된 기획·설계 문서와 이미지·사운드로 만든 30초 클릭 게임입니다. HTML, CSS, 순수 JavaScript만 사용합니다.

## 실행

`index.html`을 더블 클릭하여 Chrome, Edge, Safari, Firefox 등 최신 브라우저에서 여세요. 설치, 빌드, 로그인, 인터넷 연결이 필요하지 않습니다. `index.html`, `css`, `js`, `assets`는 같은 프로젝트 폴더 안에 유지해 주세요.

## 플레이

1. **게임 시작**을 누릅니다. 30초 타이머와 배경음이 시작됩니다.
2. 나타나는 황금별을 마우스로 클릭하거나 손가락으로 터치합니다. 별 하나에 1점이며, 별은 즉시 다른 위치로 이동합니다. 빈 공간에는 감점이 없습니다.
3. 30초가 끝나면 게임 영역 아래에서 최종 점수를 확인합니다. **20점 이상**이면 성공입니다.
4. **다시 하기**를 누르면 점수와 시간, 배경음이 초기화됩니다.

상단 소리 버튼으로 배경음과 효과음을 함께 켜고 끌 수 있습니다. 마지막 5초에는 시간 표시가 붉게 바뀝니다. 최고 기록은 현재 브라우저에 저장되며 저장소가 차단된 환경에서도 게임은 동작합니다. 브라우저의 소리 재생 제한으로 음원이 재생되지 않아도 플레이할 수 있습니다.

## 파일 구성

- `index.html`: 게임 화면과 접근성 구조
- `css/style.css`: PC·모바일 반응형 화면, 클릭 효과, 마지막 5초 표시
- `js/game.js`: 상태 관리, 타이머, 별 이동, 점수·결과, 오디오와 최고 기록
- `assets/images/star.png`: 제공된 황금별 이미지
- `assets/images/background.png`: 제공된 게임판 배경
- `assets/images/trophy.png`: 성공 시 표시하는 트로피
- `assets/sounds/`: 배경음, 클릭음, 성공음, 종료음
- `game-plan.md`, `game-design.md`: 원본 기획·설계 문서

## GitHub Pages에 올리기

프로젝트 파일 전체를 GitHub 저장소에 올린 다음, 저장소의 Pages 설정에서 파일이 있는 브랜치와 루트 폴더를 선택하면 정적 사이트로 제공할 수 있습니다. 모든 리소스는 상대 경로를 사용합니다. 이 개발 작업에는 외부 저장소 생성이나 공개 배포는 포함되지 않았습니다.

## 확인할 동작

- 시작 전에는 0점, 30초이며 황금별은 숨겨집니다.
- 클릭·터치 한 번에 1점만 증가하고, 별 전체가 게임판 안에 나타납니다.
- 20점에 도달해도 30초까지 계속 플레이하며, 시간이 끝난 뒤에는 추가 득점이 불가능합니다.
- 결과는 게임판 아래에 표시되고, 재시작 시 점수·시간·음원이 초기화됩니다.
- 창 크기를 바꾸어도 별이 게임판을 벗어나지 않습니다.
- 브라우저 탭을 전환해도 종료 시각 기준으로 남은 시간이 계산됩니다.

브라우저별 저장소·오디오 정책에 따라 최고 기록 저장과 소리 재생 여부는 달라질 수 있습니다.
